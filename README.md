# KELOKRA — Modern Multi-Tenant SaaS Point of Sale

Platform Kasir berbasis **Software as a Service (SaaS) Multi-Tenant** dengan identitas visual **KELOKRA** (`Emerald #10B981` & `Deep Navy #0F2933`).

Seluruh data awal pada sistem ini telah **dikosongkan (0 data)** agar siap langsung digunakan untuk menginput produk, stok, transaksi, pelanggan, dan keuangan asli Anda.

---

## Cara Jalankan di Lokal

```bash
npm install
npm run dev
```

Buka `http://localhost:3000` di browser.

---

## Cara Upload & Deploy ke Vercel

```bash
npx vercel
```
Atau unggah repository ini ke GitHub lalu hubungkan ke [vercel.com](https://vercel.com).
